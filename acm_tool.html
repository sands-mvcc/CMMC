🎓 Student Instructions
  • Start by adding your organization's roles and assets using the Controls Panel below. Use the asset naming convention: CUI-001, SPA-001, CRMA-001, OOS-001.
  • Once roles and assets are added, the Access Control Matrix will appear. Click any cell to set or change the permission for that Role ↔ Asset combination.
  • Permissions: A = Admin (full control) | W = Write (read + modify) | E = Execute (run operations) | R = Read only | – = Deny (no access).
  • Apply the Principle of Least Privilege — only grant the minimum access each role requires to perform its job function.
  • Every permission change requires a justification — these are recorded in the Audit Log below.
  • Use 📊 Compliance Report to check your matrix for over-provisioned roles. Use 💾 Save (Ctrl+S) to preserve your work.
