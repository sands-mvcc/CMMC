Access Control Matrix for CMMC Level 2 Audit Readiness

Professor's Note: This application helps you document the access control mechanisms critical for CMMC Level 2 compliance. Remember, the goal is tangible evidence that enforces the **Principle of Least Privilege** (AC.L2-3.1.5) and controls the flow of CUI.

Report Metadata

1. Technical Access Control Matrix (ACM)

Purpose: Basic visualization of system-level permissions (Subjects vs. Resources/Objects) to ensure controlled access.

Subjects Objects/Resources Permissions Actions

2. Shared/Customer Responsibility Matrix (SRM/CRM)

Purpose: Defines control ownership, especially for systems using external partners (e.g., Cloud Service Providers) handling CUI.

Subjects Objects/Resources Responsibility (Permission) Share Partner Actions

3. CMMC Audit-Ready Access Control Matrix (Verification Model)

Purpose: Provides C3PAO-ready evidence for **Least Privilege** (AC.L2-3.1.5) by linking access to justification and proof. This is the core documentation needed for a successful audit.

Subject Identifier Object/Resource Permission Level Justification/Business Need Supporting Evidence Link (Artifact) Actions
