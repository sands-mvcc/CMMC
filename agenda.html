NCyTE CMMC v2 Workshop: AI-Powered

Workshop Overview

This intensive 2-day workshop provides participants with essential knowledge about CMMC requirements while demonstrating how artificial intelligence can revolutionize the documentation and compliance tracking process...

Learning Objectives

  • Strategic Understanding: Explain the three CMMC certification levels, phased implementation timeline, and financial/competitive impact.
  • Technical Knowledge: Understand scoping elements, documentation components, and the role of C3PAOs.
  • AI Implementation: Leverage AI for documentation, dashboards, and compliance maintenance.
  • Practical Application: Develop CMMC roadmap, resource plans, and AI-enabled compliance strategies.

Part One: CMMC Program Fundamentals

  • Current State and Timeline
  • Three-Tier Framework Deep Dive: Levels 1, 2, 3
  • Financial Impact and Competitive Advantage

Part Two: Core Implementation Requirements

  • 17 NIST SP 800-171 Rev. 3 Control Families
  • Key changes from Rev. 2 to Rev. 3

Part Three: Implementation Planning and Next Steps

  • Organizational Readiness Assessment
  • Resource Planning and Timeline Development
  • Action Plan Development

Workshop Agenda — Day Two

  • Automation Strategies

Part Six: Building a CMMC GPT

  • Planning, Data Preparation, Training, Configuration
  • Integration, Testing, Deployment, Maintenance
